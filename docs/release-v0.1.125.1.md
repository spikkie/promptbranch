# Release v0.1.125.1

## Type and baseline

- release type: repair
- repair of: `v0.1.125`
- accepted/current input baseline remains: `v0.1.124`
- scope advancement: forbidden

## Root cause repaired

The `v0.1.125` candidate test exposed a repeatability defect. A clean full test passed, but its `compileall` validation wrote `.pyc` files below `templates/pbai/**/__pycache__`. A later structural template-snapshot test recursively read every file as UTF-8 and failed on generated bytecode.

## Changes

1. Release-validation groups set `PYTHONPYCACHEPREFIX` to a unique directory inside their isolation root.
2. `.promptbranch-release.json` invokes `scripts/compileall-isolated.py` for repository compilation validation.
3. Template snapshot comparison reads only expected tracked source files and excludes `__pycache__`, `.pyc`, and `.pyo` artifacts from the visible tracked-file set.
4. Regression tests prove isolated `compileall` produces bytecode outside the repository and leaves `templates/pbai` cache-free.
