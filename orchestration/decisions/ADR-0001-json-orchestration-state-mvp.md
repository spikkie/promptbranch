# ADR-0001 — JSON Orchestration State MVP

## Status

Accepted for v0.1.0 planning foundation.

## Decision

Start a new v0.1.x MVP line to represent orchestration as typed JSON state surfaces.

## Context

Final Artifact Intake proves verified ZIP ingress/adoption. The next capability is planning state before artifacts exist.

## Consequences

v0.1.0 adds planning docs, schemas, examples, and a state machine. Runtime orchestration is deferred.
