# Promptbranch glossary

- **Accepted** — candidate explicitly accepted after required validation; not necessarily current yet.
- **Adopted/current** — immutable artifact selected as project-scoped authoritative current.
- **Artifact authority** — version plus immutable SHA and project-scoped current resolution, not filename alone.
- **Candidate** — immutable artifact/runtime under validation before acceptance/adoption.
- **Control projection** — tracked project documents reflecting authoritative current and the rolling plan.
- **Evidence** — structured proof binding operation inputs, identities, observed result and verdict.
- **Fail closed** — ambiguous/unknown/contradictory state does not silently become success or fallback behavior.
- **MCP tool** — deterministic callable surface with explicit risk/authority contract.
- **Project Source** — ChatGPT Project material; useful as mirror/input/evidence but not artifact-current authority.
- **Skill** — bounded procedure with risk, allowed tools and prechecks; a skill does not itself grant mutation authority.
- **Task/conversation** — the correlated working chat/message context; conversation identity can change when starting a new Project chat.
- **Workspace/Project** — PB's active ChatGPT Project context and associated state.
